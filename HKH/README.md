# HKH - Flask REST API

## Overview

HKH is a Flask-based REST API project.

## Development Setup

To clone the repository:

`git clone https://github.com/NYUTandonStudent/HKH.git`

## Production Build

To build the project for production:

make prod

Running Tests

If the Makefile provides the all_tests target, run the automated test suite locally using:

make all_tests

## CI/CD

The workflow configuration is located at:

`.github/workflows/main.yml`


The GitHub Actions workflow was successfully executed on the `master` branch.
